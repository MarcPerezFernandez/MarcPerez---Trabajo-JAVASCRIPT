# La Sierra – Proyecto Fin de Módulo

Proyecto web desarrollado como trabajo final del módulo, utilizando HTML, CSS y JavaScript.

Simula la web de una estación de esquí ficticia llamada "La Sierra".

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API

---

## 📄 Estructura del proyecto

- **Inicio**: presentación de la empresa, noticias, ofertas y secciones informativas.
- **Galería**: carrusel dinámico de imágenes de las pistas.
- **Contacto**: formulario con validación JavaScript y mapa.
- **Presupuesto**:
  - Selección de tipo de estancia.
  - Extras opcionales.
  - Cálculo dinámico del precio.
  - Descuento del **10% a partir de 3 días**.
  - Gestión de productos añadidos y eliminación.

---

## 🧮 Lógica del presupuesto

- El usuario selecciona una estancia y la añade al presupuesto.
- Puede añadir extras mediante checkboxes.
- El precio final se calcula en función del número de días.
- A partir de **3 días de estancia**, se aplica automáticamente un **10% de descuento**.
- El presupuesto se actualiza en tiempo real mediante JavaScript.

---

## 📱 Diseño y usabilidad

- Diseño responsive.
- Estilo moderno con detalles en azul eléctrico.
- Navegación generada dinámicamente mediante JavaScript.
- Footer dinámico cargado desde archivo JSON.

---

## Cómo ejecutar el proyecto

Abrir el archivo `index.html` en un navegador web.
